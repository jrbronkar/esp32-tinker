# ESP32 IMU C2

Two-node ESP32-S3 prototype for an IMU-equipped vehicle and a command-and-control node with an emergency-stop control.

## Hardware on hand

- 2 × ESP32-S3 DevKitC-1
- 2 × MPU6050 IMU modules
- Breadboards and jumper wires
- 4 × capacitive soil-moisture sensors (available for ADC experiments)

Repository initialized. Firmware structure and hardware bring-up are next.
